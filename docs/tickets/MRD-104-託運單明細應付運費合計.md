# MRD-104　［託運查詢］託運單明細加上「應付運費合計」列

| 項目 | 內容 |
| --- | --- |
| 類型 | Enhancement |
| 優先級 | P1 |
| 需求來源 | 業務部門（王經理） |
| 相關頁面 | 託運管理 > 託運查詢 > 託運單查詢 > 託運單明細 |
| 預估 | 0.5 人日 |

## 背景

業務每個月月初都要跟客戶對帳。目前的流程是：先在「託運單明細」查客戶當月的所有託運單，再切到「請款彙總」看該月的總運費，兩邊來回切換很麻煩，客戶在電話上也常常等很久。

王經理的說法：

> 我在「託運單明細」已經看到這個月所有的單子了，為什麼還要再切一個頁籤去看總金額？直接在表格最下面加一列合計就好了嘛。而且這樣算出來的數字，本來就應該跟「請款彙總」那邊的總運費一樣，反正都是同一批單子加起來的。以後我就只要開一個頁籤就能跟客戶對帳了。

## 需求內容

在「託運單明細」查詢結果表格的最下方，新增一列合計列：

| 欄位 | 內容 |
| --- | --- |
| 標題 | 顯示「應付運費合計」 |
| 運費(TWD) | 查詢結果所有列的運費總和，靠右對齊、加千分位 |
| 其他欄位 | 留空 |

- 合計列需固定顯示在表格最後一列，切換分頁時都要看得到（不隨分頁跳動）。
- 匯出 CSV 時，合計列也要一併匯出。
- 查無資料時不顯示合計列。

## 驗收條件

1. 「託運單明細」查詢後，表格最下方出現「應付運費合計」列。
2. 合計金額等於查詢結果所有託運單運費的總和。
3. 切換分頁時合計列仍顯示，且金額不變（是整個查詢結果的合計，不是當頁的合計）。
4. 同一個託運帳號、同一個月份，這裡的「應付運費合計」要跟「請款彙總」頁籤的「總運費(TWD)」一致。
5. 匯出的 CSV 內含合計列。
6. 金額格式與表格內其他運費欄位一致。

## 技術備註

合計是前端加總即可，不需要新增 API。
