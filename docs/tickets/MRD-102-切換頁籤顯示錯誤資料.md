# MRD-102　［託運查詢］切換頁籤後直接顯示上一個頁籤的查詢結果

| 項目 | 內容 |
| --- | --- |
| 類型 | Bug |
| 優先級 | P1 |
| 回報人 | 客服部門（客戶申訴） |
| 相關頁面 | 託運管理 > 託運查詢 > 託運單查詢 |
| 環境 | UAT / 本機皆可重現 |

## 客戶描述

> 我查完託運單明細之後，點「請款彙總」，畫面直接跳出一個表格，欄位是請款彙總的欄位，但裡面幾乎都是空白的，只有託運帳號有值，筆數還跟我剛才查的託運單一樣。我根本還沒按查詢，它就先給我一個表格了。要重新整理整個頁面才會回到查詢畫面。

## 重現步驟

1. 登入後進入「託運管理 > 託運查詢 > 託運單查詢」。
2. 停在「託運單明細」頁籤，選擇客戶「恆宇貿易股份有限公司」、託運帳號「SA-88120001」，出貨日期用預設區間，按「查詢」。
3. 確認查詢結果有資料（預設區間約 20 筆，會有多頁）。
4. 點選「請款彙總」頁籤。

## 實際結果

- 「請款彙總」頁籤沒有顯示查詢條件表單，而是直接顯示查詢結果區塊。
- 表格的欄位標題是請款彙總的欄位（帳務月份、託運件數、總重量…），但資料列除了「託運帳號」以外都是空白。
- 資料筆數與步驟 2 查詢到的託運單筆數相同。

## 預期結果

- 切換到任一頁籤時，該頁籤都應該從查詢條件表單開始。
- 不同頁籤的查詢結果不可互相污染；前一個頁籤查到的資料不應出現在後一個頁籤。
- 反向操作（先查「請款彙總」再切到「託運單明細」）也應正常。

## 驗收條件

1. 依重現步驟操作，切到「請款彙總」時顯示的是查詢條件表單。
2. 在「請款彙總」查詢後切回「託運單明細」，同樣顯示查詢條件表單，不殘留前一次結果。
3. 在同一個頁籤內按「重新查詢」的行為不受影響。
4. 修正後請補上可以擋住這個問題再次發生的測試。
