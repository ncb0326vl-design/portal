# MRD-103　［託運查詢］託運單明細結果需可依運費排序

| 項目 | 內容 |
| --- | --- |
| 類型 | Enhancement |
| 優先級 | P3 |
| 需求來源 | 業務部門 |
| 相關頁面 | 託運管理 > 託運查詢 > 託運單查詢 > 託運單明細 |
| 預估 | 0.5 人日 |

## 背景

業務在跟客戶談年度運費合約前，會想先看客戶當期運費最高的幾筆託運單，作為議價的依據。目前結果表格是依出貨日期排列，業務只能自己匯出 CSV 到 Excel 再排序，多繞一圈。

## 需求內容

「託運單明細」的查詢結果表格，需可點擊「運費(TWD)」欄位標題切換排序（升冪／降冪）。

## 驗收條件

1. 點擊「運費(TWD)」欄位標題一次為升冪，再點一次為降冪，欄位標題需有可辨識的排序方向指示。
2. 排序後分頁功能仍正常（例如每頁 10 筆、切到第 2 頁，順序需延續）。
3. 排序為前端行為，不需重新呼叫 API。
4. 其他欄位一併變成可排序不影響驗收。

## 技術備註

送出前請確認有沒有既有的機制可以直接支援，不需要為此新增元件。
